📋 Overview

A complete Speech-to-Text (STT) and Text-to-Speech (TTS) application with support for 25+ languages including major Indian languages. Built with Flask, SpeechRecognition, and gTTS, containerized with Docker for easy deployment.

✨ Key Features

🎤

Speech-to-Text

Upload audio files (WAV, MP3) for transcription

🔊

Text-to-Speech

Convert text to speech in 25+ languages

🌍

Multilingual

Hindi, Tamil, Telugu, Kannada, and more

📥

Download MP3

Download generated speech as MP3

🐳

Dockerized

Containerized for easy deployment

🧪

Testing

Unit tests with pytest and CI/CD

🛠️ Technology Stack

  • Backend: Flask, Python 3.11
  • STT: SpeechRecognition (Google Speech API)
  • TTS: gTTS (Google Text-to-Speech)
  • Frontend: HTML, CSS, JavaScript
  • Containerization: Docker, Docker Compose
  • Testing: Pytest, Pytest-Cov
  • CI/CD: GitHub Actions

🚀 Quick Start

# Clone the repository git clone https://github.com/DARSHAN13302/stt-tts-multilingual.git cd stt-tts-multilingual # Run with Docker docker-compose up -d # Open in browser open http://localhost:5000

📊 API Endpoints

  • GET / - Web interface
  • GET /health - Health check
  • POST /stt - Upload audio for transcription
  • POST /tts - Generate speech from text
  • POST /tts/download - Download speech as MP3

🌍 Supported Languages

Indian Languages: Hindi, Tamil, Telugu, Kannada, Malayalam, Bengali, Marathi, Gujarati, Urdu, Punjabi

Global Languages: English, Spanish, French, German, Italian, Portuguese, Russian, Chinese, Japanese, Korean, Arabic, Dutch, Polish, Turkish, Vietnamese, Thai, Indonesian
