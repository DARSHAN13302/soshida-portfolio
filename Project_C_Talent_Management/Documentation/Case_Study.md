# Project C: Talent Management Flow

## The Brief
A recruitment platform needs an "Add to Shortlist" flow for hiring managers.

## My Role
- UX/UI Design
- State Management
- User Flow Design

## User Flow
1. Browse candidate profiles
2. Click "Save to Shortlist"
3. Success confirmation
4. View shortlisted candidates

## States Designed
- Happy Path: User saves candidate → Success toast → Profile moves to Shortlist
- Empty State: No candidates in shortlist yet
- Error State: Duplicate candidate error
- Loading State: Skeleton screens

## Micro-interactions
- Button press feedback
- Toast notifications
- Smooth transitions
